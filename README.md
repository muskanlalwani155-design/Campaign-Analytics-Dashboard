# Campaign Analytics & Attribution Dashboard

An interactive, responsive marketing analytics dashboard engineered with pure JavaScript (ES6+), HTML5, and CSS3. The application visualizes multi-channel campaign performance, tracks conversion attribution, and provides dynamic data filtering with interactive charts.

---

**Live Demo:** [View Live Dashboard](https://muskanlalwani155-design.github.io/Campaign-Analytics-Dashboard/)  
**Source Code:** [GitHub Repository](https://github.com/muskanlalwani155-design/Campaign-Analytics-Dashboard)

---

##  Tech Stack

* **Markup & Structure:** HTML5 (Semantic elements)
* **Styling & Layout:** CSS3 (Flexbox, CSS Grid, Custom Variables, Media Queries)
* **Core Logic & DOM Manipulation:** JavaScript (ES6+, Event Listeners, State Management)
* **Data Visualization:** Chart.js / Dynamic Canvas rendering
* **Assets:** Custom SVG/PNG UI icons

---

##  Features

* **Multi-Channel Performance Tracking:** Displays campaign metrics including impressions, CTR, conversion rates, and total ad spend across channels.
* **Interactive Data Visualization:** Dynamic visual charts reflecting attribution shifts and trend comparisons over time.
* **Responsive Navigation:** Mobile-friendly dashboard interface with an integrated hamburger menu toggle for smaller screens.
* **Client-Side Filtering:** Real-time metrics updating based on selected time ranges or campaign channels without page reloads.
* **Clean Vanilla Implementation:** Zero external heavy framework dependencies, ensuring fast load times and clean DOM rendering.
